# Airplanes Tracker ✈️

Приложение для отслеживания и анализа данных о полетах самолетов в реальном времени с использованием API OpenSky Network и OpenStreetMap (Nominatim).

## Основные возможности
- **Загрузка данных**: Получение актуальной информации о рейсах в заданной стране или географическом райноне (Bounding Box).
- **Хранение данных**: Локальное сохранение информации в формате JSON.
- **Анализ**: Фильтрация данных по странам, ICAO-кодам и другим критериям.
- **Интерактивное меню**: Удобный консольный интерфейс для управления программой.

## Технологический стек
- **Язык**: Python 3.10+
- **Библиотеки**: `requests` для API, `pytest` для тестирования.
- **Архитектура**: ООП (Abstract Base Classes, Инкапсуляция, Модульная структура).
- **Инструменты**: Coverage для контроля покрытия тестами.

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/RomanShumakov/airplanes_tracker.git
```

2. Установите зависимости (рекомендуется использовать venv):
```bash
poetry install
```

3. Запустите приложение:
```bash
python main.py
```

## Тестирование
Для запуска тестов и генерации отчета о покрытии выполните:
```bash
pytest --cov=src --cov-report=html tests/
Результаты тестов будут доступны в папке htmlcov/.
```

## Структура проекта
- src/ — основной исходный код (логика, хранилище, вьюшка).
- data/ — JSON-файлы для хранения данных.
- tests/ — модульные тесты.
